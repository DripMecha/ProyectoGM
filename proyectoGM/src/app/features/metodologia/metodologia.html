PROYECTO GENUINE MOTORS

Metodología de desarrollo

Para desarrollar nuestro sistema web Genuine Motors, organizamos el trabajo en diferentes fases que permiten planificar, desarrollar, integrar y verificar cada funcionalidad del proyecto.

Fases del desarrollo

Nuestro proyecto se desarrolló siguiendo las siguientes etapas:

01

Diseño y base

Se organizaron las actividades del equipo y se definió la estructura inicial del sistema.

  • Análisis de los requerimientos.
  • Distribución de responsabilidades.
  • Diseño de las interfaces.
  • Creación de ramas y estructura del proyecto.
02

Desarrollo

Se realizó la programación de las diferentes secciones y funcionalidades del sistema.

  • Desarrollo de componentes con Angular.
  • Implementación de estilos e interfaces.
  • Desarrollo del backend con Spring Boot.
  • Conexión con la base de datos MySQL.
03

Integración y pruebas

Se integraron los avances de cada integrante y se verificó el funcionamiento de las diferentes secciones.

  • Actualización de las ramas de GitHub.
  • Revisión de Pull Requests.
  • Integración de los componentes.
  • Corrección de errores y pruebas.
04

Cierre y sustentación

Se preparó la presentación del avance y se organizaron los resultados obtenidos durante el desarrollo.

  • Preparación de las diapositivas.
  • Organización de la demostración.
  • Ensayo de la exposición.
  • Verificación final del proyecto.

Trabajo colaborativo con GitHub

Cada integrante trabaja en una rama independiente para desarrollar su sección. Al finalizar, envía sus cambios mediante un Pull Request hacia la rama develop. El coordinador revisa e integra los cambios y, cuando el proyecto está listo, se actualiza la rama main.

Rama individual → Pull Request → Develop → Main
